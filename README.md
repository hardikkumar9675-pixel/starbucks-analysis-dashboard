# ☕ Starbucks Nutrition Analytics Dashboard

## 📌 Project Overview

This Power BI dashboard provides an interactive analysis of Starbucks beverage nutrition data. The report helps users explore beverage categories, compare nutritional values, and identify high-caffeine drinks through dynamic visualizations and filters.

The dashboard is designed to deliver insights into calories, sugar, protein, and caffeine content across different Starbucks beverage categories.

---

## 🎯 Objectives

* Analyze nutritional information of Starbucks beverages.
* Identify beverages with the highest caffeine content.
* Compare average calories across beverage categories.
* Understand beverage category distribution.
* Enable interactive filtering for better decision-making.

---

## 📊 Dashboard Features

### KPI Cards

* Total Beverages
* Average Sugar
* Average Calories
* Average Caffeine

### Interactive Filters

* Protein Range
* Beverage Preparation Type

### Visualizations

* Average Calories by Beverage Category
* Starbucks Global Presence Overview
* Beverage Category Distribution (Donut Chart)
* Average Caffeine by Category
* Top 5 Highest Caffeine Beverages

---

## 📈 Key Insights

* Coffee category contains the highest average caffeine content.
* Smoothies have the highest average calorie count among beverage categories.
* Frappuccino and Espresso-based drinks contribute significantly to overall beverage distribution.
* Top caffeine beverages help users identify stronger coffee options quickly.

## 📂 Dataset Information

**Source:** Starbucks Beverage Nutrition Dataset (Excel File)

The dataset contains nutritional information for Starbucks beverages, including:

* Beverage Category
* Beverage Name
* Beverage Preparation
* Calories
* Total Fat (g)
* Saturated Fat (g)
* Sodium (mg)
* Carbohydrates (g)
* Cholesterol (mg)
* Dietary Fiber (g)
* Sugars (g)
* Protein (g)
* Caffeine (mg)

The data was imported from Excel into Power BI, where it was cleaned, transformed, and modeled for analysis.
